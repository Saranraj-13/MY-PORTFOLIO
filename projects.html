1. Smart Hospital Management System

A comprehensive database-driven medical administration platform engineered to simplify patient registrations, appointment queue routing, electronic health records (EHR), and bed availability tracking in real-time.

Key Features & Technical Highlights:

  • Automated triage queue management prioritizing urgent medical cases.
  • Normalized SQL relational database design enforcing transactional data integrity.
  • Role-based access control (RBAC) for doctors, receptionists, and patients.
  • Responsive, high-contrast user interface accessible via desktop and tablet devices.

Technologies Used:

  • HTML5
  • CSS3
  • Vanilla JavaScript
  • SQL / Relational DB

2. Plastic Degradation — Minor Project

An interdisciplinary minor research initiative combining biological environmental science with computer simulation modeling to evaluate microbial degradation pathways of synthetic polymers (PET and polyethylene).

Key Features & Technical Highlights:

  • Computational modeling of enzymatic reaction rates on microplastics over time.
  • Python data analytics scripts parsing biological sequence datasets.
  • Comparative analysis of temperature, pH, and enzyme concentrations on breakdown rates.
  • Interactive data visualizations presenting degradation efficiency curves.

Technologies Used:

  • Python
  • Data Analytics
  • Bioinformatics
  • Matplotlib

3. Personal Portfolio Website

A modern, production-grade, multi-page portfolio website crafted specifically for the Thiranex internship task. Built using strict HTML5 semantic architecture and WCAG 2.1 AA accessibility standards.

Key Features & Technical Highlights:

  • 100% semantic HTML5 layout with zero unsemantic wrapper clutter.
  • Full keyboard accessibility, high contrast colors, and skip-to-content functionality.
  • Client-side form validation with dynamic screen-reader error announcements (`aria-live="polite"`).
  • Comprehensive SEO optimization including Open Graph and canonical metadata.

Technologies Used:

  • Semantic HTML5
  • CSS3 Variables
  • Vanilla JS
  • WCAG 2.1 AA
